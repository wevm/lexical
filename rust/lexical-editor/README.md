at parity with the JS implementation. See the workspace's
[README](https://github.com/wevm/lexical/blob/main/rust/README.md),
[DESIGN.md](https://github.com/wevm/lexical/blob/main/rust/DESIGN.md),
[PARITY.md](https://github.com/wevm/lexical/blob/main/rust/PARITY.md) and
[CHANGELOG.md](https://github.com/wevm/lexical/blob/main/rust/CHANGELOG.md).
